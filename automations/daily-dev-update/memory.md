排程：每天 09:00，launchd `com.po-chi.claude-daily-dev-update`。
與 Codex 的 `每日開發工具更新`（已改到 14:00）並存，兩份互相對照。

每次執行由 Claude 自己在下方**附加**一節，不要覆蓋既有內容。

## 2026-07-27 建立

- 建立 `~/.claude/automations/daily-dev-update/`：`PROMPT.md`（工作定義）、`run.sh`（launchd 進入點）、`logs/`（每日輸出）。
- 這份的存在理由：Codex 端同名 automation 曾連續被「唯讀檔案系統 + 封鎖 DNS」的 managed sandbox 擋住。後續 rollout 證據已排除 project trust 與 Mac 檔案權限問題；限制是由 Desktop 背景 scheduler 在首個 turn context 前注入。
- 因此更新執行走 user-level launchd + Codex CLI，不經過 Codex Desktop Scheduled permission resolver；Desktop Scheduled 僅唯讀回報結果。
